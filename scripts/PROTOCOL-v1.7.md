## V1 词形/结构惊讶分离 + 纠正剂量扫描（公开问题 12）→ exp12

**背景（exp10b 实测）**：撤+纠 B 臂 drant 0.8589 vs 纯撤销 D 臂 1.0146 vs 未教基线 1.021——纠正式与错误用法共享词形 n-gram（`the drant` 等）→ 回填 ≈ 0.156 bpc。缺两件东西：(a) 词形惊讶与结构位置惊讶的**分离度量**；(b) 模板语言无法消除 `the drant` 2-gram 共享 → "最小前缀共享纠正式"的可实现操作化 = **纠正剂量最小化**（m 次重复扫描）+ **回填来源归因**（词形泄漏 vs 模板强化的对照臂）。

**机制规格**：
- 三种度量：(P1) 结构探针 = 原错误用法探针（drant 主语位 / blarn 宾语位）；(P2) 正确位置探针 = 目标词在真实句法位的新句 ×3（独立 rng=777 生成，不污染主 rng）；(P3) **探针内字节段分解** = P1 探针的逐字节 bits 按词形段（目标词 5 字节）与结构段（其余字节）分桶——分离度量的微操作化。
- 六臂重放（全部 γ=0 撤销底座，与 exp10b 同种子同账本）：BASE（只喂 BASE，测 P1/P2 未教基线）；D（纯撤销，复现 1.0146）；F（纠正位替换为 3 句不含目标词的普通句——**模板强化对照**，rng=888）；E1/E2（纠正式重复 m=1/2）；B（m=3，复现 0.8589）。
- 世界与 exp10b 逐字节一致：主 rng 消耗顺序 seed(20261108)→shuffle→verify_flags→P1 探针→INTERFERE→BASE 完整复刻；P2/F 探针用独立 rng。

**预测**（全部可证伪）：
1. 回归：D 臂 drant P1 = 1.0146±0.005、blarn P1 = 1.0798±0.005；B 臂 drant P1 = 0.8589±0.005、blarn P1 = 0.9191±0.005（γ=0 重放无 rng 消耗，应近逐位）。
2. BASE 臂：drant P1 ≈ 1.021±0.01、blarn P1 ≈ 1.075±0.01（对齐 exp10 未教基线）。
3. 分离（核心）：B 臂 drant P2 ≤ BASE P2 − 0.10（正确用法学到）且 B 臂 drant P1 ≤ BASE P1 − 0.10（回填存在）——两维同时成立 ⟹ 词形/结构信念可分离测量，"部分纠正"是真实的中间态。
4. 字节段归因：B 与 D 的 P1 差中，词形段贡献 ≥ 60%（回填集中在目标词字节，非结构段）。
5. 剂量单调：P1(m) 与 P2(m) 随 m∈{0,1,2,3}（0=D）单调不增；存在 m*∈{1,2} 使 P1(m*) ≥ 0.95 且 P2(m*) ≤ BASE P2 − 0.05（最小剂量纠正存在；预测 m*=1）。
6. F 臂（模板对照）：|P1(F) − P1(D)| ≤ 0.02 ⟹ 回填主因 = 词形 n-gram 泄漏，模板强化可忽略。
7. 对照词（vexol/quibnar/sneel）全臂间 |Δ| ≤ 0.05；blarn 方向同构（幅度可不同）。

## V2 谱稠密化：楼梯消除与 β=γ 收敛（公开问题 13）→ exp13

**背景（exp7b 实测）**：R=2 稀疏几何谱（12 层）下 coupled γ=1 → β=−0.522、ebb γ=0.126 → β=−0.413——方向保序但幅度压缩（离散谱对数周期楼梯 + 2^i 滞后网格与楼梯相位锁定）。锚点 15 断言稠密/连续谱下 β→γ，未验证。

**机制规格**：
- 复用 exp7b 单池逐出机制（同流同种子 [1,2,3]、CAP_POOL=96、w_k 几何）。
- 扫描 R ∈ {2.0, 1.6, 1.4, 1.25, 1.125}，层数 N(R) = 1 + ceil(11/log2(R))（固定总尺度跨度 ≈ 2^11：N = 12/17/24/35/65）。
- 两 γ 臂：coupled（q∝w，γ=1）与 ebb（q∝w^0.126，γ=0.126）。
- 楼梯度量：**对数周期谐波指数 SI** = 拟合 log S = a + b·log L + c1·sin(2π log L / log R) + c2·cos(...) 后周期项解释的残差方差比例（SI=1−SSR_周期/SSR_线性）。滞后网格 = 对数均匀 40 点（1..1024，打破 2^i 相位锁定）；R=2 臂另跑 2^i 网格做回归对照（应复现 −0.522/−0.413）。
- 敏感性臂：R=1.25 池容量 8×N=280（每层人口保持 ~8，对照固定池 96 的人口稀疏效应）。

**预测**：
1. 回归：R=2（2^i 网格）coupled β = −0.522±0.02、ebb β = −0.413±0.02。
2. 收敛：|β(R)−γ| 随 R↓ 单调不增（允许平局）；R=1.25 时 coupled β ∈ [−1.15, −0.85] 且 ebb β ∈ [−0.22, −0.05]。
3. 楼梯消除：SI 随 R 单调下降；SI(1.25) ≤ SI(2.0)/2。
4. 实现代价：报告 N(R) 与每层平均人口（96/N）。R=1.125（65 层、~1.5 条/层）预测人口稀疏产生噪声偏移（β 偏离或 R² 下降），仅记录不判定。
5. 敏感性：池 280 臂 R=1.25 的 β 与池 96 臂同向（|Δβ| ≤ 0.15）⟹ 结论不依赖池容量。
6. 稳健：γ=1 与 γ=0.126 两臂收敛方向一致。

## V3 逃逸链 ρ/η 敏感性扫描（锚点 11 规格化）→ exp14

**背景（exp3b 实测）**：单点 ρ=0.999, η=0.15 → 风暴 9.644→6.758、非风暴税 −0.0101、恢复 0.011。规格缺参数鲁棒性面。真实多模态全尺寸沙盒不可行，**参数敏感性扫描可行且必要**。

**机制规格**：
- **冻结深度组件**：CTW raw bits 与探针 bits 只跑一次（与 exp3b 逐字节同流同种子，回归校验风暴 raw=9.644）；FastUni(ρ) 与混合权重(η) 纯 Python 重放——CTW 独立于 ρ/η，重放精确等价（exp3b 的 mix 因果顺序保留）。
- 网格：ρ ∈ {0.99, 0.995, 0.999, 0.9995, 1.0} × η ∈ {0.05, 0.15, 0.3, 0.5} = 20 组合。
- 指标：风暴 bpc、非风暴平均税、恢复窗超额（storm_hi+200..456）、正常段最差 4KB 窗税、风暴燃入首 256B。
- **v1.6 规格判定面**（逐组合）：风暴 <8 ∧ 税 ≤0.02 ∧ 恢复 ≤0.02。通过组合集 = 稳健窗。

**预测**：
1. 回归：ρ=0.999, η=0.15 复现风暴 6.758±0.01、税 −0.0101±0.002、恢复 0.011±0.005（重放逐位等价）。
2. η 效应：η=0.05 风暴 bpc > 7.0（转向过慢）；η=0.5 平均税 > 0.02 或正常段最差 4KB 窗税 > 0.05（过度摆动伤正常段）。
3. ρ 效应：ρ=1.0（无遗忘）恢复窗超额 > 0.02（风暴污染快速模型，违反规格）；ρ=0.999 与 0.9995 恢复 ≤0.02。
4. 稳健窗非空且不窄：≥ 8/20 组合通过全规格（规格非刀锋参数）。
5. 下界兜底：全部 20 组合风暴 bpc < 8（均匀组件底兜住，与 ρ/η 无关——混合不输定理的组件先验底作用面）。

## V4 尾部探针配额自适应（ε-尾质量作为预算信号）→ exp15

**背景（exp6b 实测）**：固定配额下尾族最坏 19.61 一骑绝尘（rollout 1.86 / beam 4.18），ε-尾质量 mean 0.0082/max 0.0387。问题：预算分配对模型状态盲——纯文本期尾探针浪费、模因期尾探针恰好命中。假设：**ε-尾质量是尾探针边际收益的有效预测器**。

**机制规格**：
- 复用 exp6b 的 PPM(orders=6) + 流（同种子 42，M 模因注入 60K 后）。
- 12 时点：[8K, 16K, 24K, 32K, 40K, 48K, 55K, 65K, 75K, 85K, 95K, 110K]——覆盖纯文本期（前 60K）与模因期（后 60K）的 ε-尾动态。
- 每时点红队总预算 950 查询（束搜索砍掉——exp6b 中 beam 4.18 非决定性；rollout 族与 tail 族两分）：
  - fixed：rollout 475 / tail 475（等分对照）
  - adaptive：先花 50 查询测 ε-尾质量 m → α_tail = clip(m/0.016, 0.1, 0.9)（标定：m=0.0082（exp6b 实测均值）→ α=0.5）→ tail = round(950α)、rollout = 其余
  - oracle：事后最优族全额 950（上界对照；= max(rollout_950, tail_950)）
- 回归检查：55K 时点完整复跑 exp6b 三族红队（8011 查询同路径）→ worst = 19.6127±0.01。
- 核心相关性：跨 12 时点，ε-尾质量 m(t) 与尾族相对优势 adv(t) = tail_best(fixed 475) − rollout_best(fixed 475) 的 Pearson r。

**预测**：
1. 回归：55K 复跑 exp6b 红队 worst = 19.6127±0.01、族最坏 rollout≈1.86/tail≈19.61、ε-尾 mean ≈ 0.0082。
2. 核心相关性：Pearson r(m, adv) ≥ 0.5（ε-尾质量是有效预算分配信号——本实验的成败判据）。
3. 自适应不劣：全时点 adaptive 最坏 ≥ fixed 最坏 − 0.15 bpc。
4. oracle 差距：adaptive 最坏 ≥ oracle 最坏 − 0.3（自适应接近上界）。
5. 边际保持：模因期（M 首现后）时点 adaptive 最坏 ≥ M 首现 bpc 10.569（安全边际 >0 延续）。
6. 动态可见：ε-尾质量在 M 模因首现后上升（学习前）并在 M 学会后回落（motif_late 4.89 对应段）——曲线形状记录。
