# 实验预注册协议（跑实验前公布——防事后诸葛）

> 时间：2026-11-08。沙盒环境：CPU-only, gcc -O2, Python 3.12。所有结果按【实验·沙盒级】标注。
> 能量计量：沙盒无 RAPL，以 CPU 时间 × 假设 TDP 65W 为能量代理（同机同 TDP，比值稳健）。
> 数据：古腾堡 Moby Dick(1.27MB)/Sherlock(607KB)/Pride&Prejudice(450KB)/Alice(174KB)。
> 引擎：自研二进制 CTW（log2 域，深度可设），单机+server 双模式。

## 预注册预测（跑之前写下，输了认）

| 实验 | 预测 |
|---|---|
| 1 等能耗 bpc | (a) 无预算限制时 GPT-2 bpc 最低（若可部署）；(b) T=32s/256KB 档：CTW 有效 bpc < 3.5，GPT-2 有效 bpc > 6.5（算力不够，大部分字节退化为均匀分布）；(c) CTW ≤ gzip 且接近 xz |
| 2 文法层 few-shot | 文法+压缩 kNN 在 k≤8 时比 gzip-kNN 高 ≥10 个百分点（合成结构语言上） |
| 3 daemon 常驻(模拟) | 学习曲线随模拟日单调改善；事件风暴段预测不缺席（bpc < 8 有限） |
| 4 泛化三连 | (a) SCAN 组合分割：组合/程序归纳学习器 ≥95%，统计基线低；(b) 奇偶 2× 外推：程序归纳 ≥95%，统计基线 ≈50%；(c) one-shot 新词组合复用 ≥90% |
| 5 发育曲线 | 固定早期材料，后期模型重压缩 bpc 单调下降，总降幅 ≥15% |
| 6 红队覆盖 | 红队最坏情形平均惊讶 ≥ 实际 OOD 惊讶（安全边际 > 0） |
| 7 机器遗忘 | 相似性/干扰驱动登台产生近似幂律衰减（log-log 线性 R² > 指数拟合 R²）；随机驱逐产生指数衰减；Ebbinghaus 参照曲线形状接近干扰驱动型 |
| 8 混合采样 | 直接逐符号混合采样：长串良构率 <20%；专家承诺+类型检查 ≈100% |
| 9 双机同步 | 压缩包外交后 B 的 bpc 下降 ≥15%；第二轮双方状态等价 → 预测一致率 →100% |
| 10 听课测试 | (a) 冻结基线：所有事实惊讶下降 ≈0；(b) 无门控：噪声源假事实也被采纳；(c) 全 PIM(r_s 门控)：教师真事实下降大、噪声假事实下降小（差 ≥3 倍）；(d) r 分化：教师 >0.75，噪声 <0.55；(e) 干扰后未排练事实回弹，排练后保持 |
