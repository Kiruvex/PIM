## R1 逃逸编码（v1.6 对锚点 11 的修订）→ exp3b

**机制规格**：逃逸不是"固定 ε 洒给均匀分布"（会封顶快速模型的渐近质量），而是**模型级贝叶斯混合的先验底**：

- `p(x) = Σ_j w_j·p_j(x)`，组件 j ∈ {CTW-D24（引擎），快速单字模型（指数窗 ρ=0.999 的字节单字分布 + KT 0.5 平滑），均匀 1/256}
- 权重更新（在线、因果）：`w_j ← w_j·(p_j(x)/p(x))^η`，η=0.15，然后归一化；**权重底 1/256**（任何组件永远保留恢复通道——这就是"逃逸质量"的正确位置）
- 初始 w=(0.98, 0.016, 0.004)；流、引擎深度、种子与 exp3 完全一致（回归检查）
- 学习仍在 CTW 计数层原样进行（逃逸是预测分布的组成，不是学习的中断）——对应架构 ⑤"各层竞争预算→混合"与锚点 11 的"预测分布保留逃逸质量"

**预测**：(i) 风暴段 bpc < 8（基线 9.644；预期落点 [6.3, 7.9]）；(ii) 非风暴段混合税 ≤ 0.02 bpc；(iii) 风暴结束后 200 字节内非风暴文本 bpc 回到原始+0.02 内；(iv) 回归：原始引擎 bits 应复现 9.644。

## R2 红队尾部探针（梦魇课程修订）→ exp6b

**机制规格**：保留原候选生成（rollout+束搜索，top-q=0.9 合理性过滤），新增**候选生成 3【尾部/逃逸探针】**：每步从 full_dist 中概率最低的 4 个符号里随机取一个（**无合理性过滤**），24 条 × 24 字节 = 576 次查询。新增诊断指标：**ε-尾质量** = 采样上下文上 p<1/256 符号的总质量（逃逸前哨——OOD 的居住地）。

**预测**：(i) 新红队最坏 bpc ≥ 10（基线 4.176；真实 OOD 首现 10.569）；(ii) 安全边际（最坏 − 真实 OOD）> 0（翻转原证伪）；(iii) 最坏候选来自尾部探针族；(iv) 总查询 ≤ 20000。

## R4 S_ji 多时间尺度（v1.2 工作记忆层实现约束）→ exp7b

**解析定律（预注册）**：单池 + 层标签机制：新痕迹落层 ~ q_k；每次写入逐出一条，逐出层按 w_k·n_k（压力×人口）采样，层内均匀。则层 k 痕迹的逐写存活 ≈ e^{−h_k L}，h_k ∝ w_k；总体 `S(L) = Σ_k q_k·e^{−h_k·L}`。**入驻谱定律：q_k ∝ λ_k^γ ⟹ 涌现遗忘幂律指数 β = γ**（连续化推导；离散几何间隔产生对数周期涟漪）。稳态人口 n_k ∝ q_k/w_k——入驻谱即人口分布：排练/巩固 = 人口向慢层迁移 ⟹ γ 变小 ⟹ 遗忘变浅（ACT-R 幂律练习与幂律遗忘同源，锚点 7 的机制版）。

**三臂**（参数先验固定，不逐曲线拟合）：
- `ms12_coupled`：12 层，w_k ∝ 2^−k，q_k ∝ w_k（入驻=压力耦合，random_mixed 的直接推广）→ γ=1
- `ms12_ebb`：同 w_k；q_k ∝ w_k^0.126（用 Ebbinghaus 指数反推入驻谱——**标注为校准演示**，检验定律反向）→ γ=0.126
- `subspace8`：8 个 8 维上下文子空间，σ_k = 0.42·2^−k，相似度 = 子空间余弦均值，top-K=100（教训 4 的字面路线）

**预测**：(i) ms12_coupled：log-log R² ≥ 0.95，β ∈ [−1.3, −0.7]（解析 −1）；(ii) ms12_ebb：R² ≥ 0.95，β ∈ [−0.30, −0.02]（解析 −0.126）；(iii) 模拟曲线 vs 解析混合公式（用实测 h_k）R² ≥ 0.99（幂律确实来自层混合而非别物）；(iv) subspace8：**预测退化**——各滞后存活率与单尺度相似性相差 ≤ 0.08，top-K 近因占比 ≥ 0.98（解析理由：各向同性随机游走 E[cos(c_s,c_t)] = √(s/t) 与 σ 无关 ⟹ 子空间漂移率分化不改变平均相似度排序，教训 4 的"多子空间"字面路线单独无效）。
**回溯注记**：既有 random_mixed（2 层 10:1，γ=1）实测 β=−0.526 偏离解析 −1——窗口截断（[1/h_fast, 1/h_slow]=[55,550] 不覆盖滞后域）所致；12 层窗口 [16, 32768] 覆盖全域，应收敛到解析值。

## R6 拷贝原语（程序层存在的实证理由，反馈 5）→ exp2b

**机制规格（程序层替身）**：每类模型 = MDL 取 min{文法比特(x)，拷贝程序比特(x)}。COPY 程序：若 |x| 为偶且 x 前半 == 后半：比特 = (|x|/2)·2 + COPY_COST（程序描述长度，预注册 COPY_COST=20 bit）；否则 ∞。**四个类配同一程序库**（公平：MDL 选择，不告诉它哪类该用拷贝）。文法部分与 exp2 逐行相同。

**预测**：(i) L3 复制语言 k=1 ≥ 90%（拷贝程序零数据即可用），k=8 ≥ 85%（基线 12.7%）；(ii) 总体 k=8：文法+程序 ≥ 84%，与 gzip（81.5%）之差 ≥ 0（翻转 −3.7pp）；(iii) L1/L2/L4 各变化 ≤ ±2pp；(iv) COPY_COST ∈ {10,20,40} 敏感性：L3 结论不变。

## R5 再解释层纠正协议（v1.6 旗舰：双层日志从审计便利升格为纠正的必要条件）→ exp10b

**机制规格**：
- 记录层 = 不可变事件账本（授课/验证/撤回全部入账，含审计条目 RETRACT{模式, 纠正者, 时间}）
- 再解释层 = 痕迹权重 w_e（初始 1）
- 纠正事件（验证失败触发）三步：(1) 记录层追加 RETRACT；(2) **位置感知模式匹配**定位错误用法痕迹——主语模式 `the w (snarfs|grabs|hoists)`、宾语模式 `(snarfs|grabs|hoists) the w`——命中者 w_e ← γ；(3) 追加正确用法 ×3 新痕迹（w=1，来源=传感亲证）。撤回句本身（"no, that is wrong. "）只入记录层，不进预测器（元通信不是世界用法）。
- 预测器 = 重放构建：BASE + 每条痕迹按 w_e 概率包含（固定种子）；CTW 终态是计数的函数、顺序无关——重放与在线等价（此点本身是检验）。

**三臂**：A=旧协议（向流追加反例文本，重放语义等价复现）；B=γ0（撤销：错误痕迹权重归零）；C=γ0.25（降权：概率包含）。

**预测**：(i) A 复现原失败且顺序无关性成立：drant 假信念 verify bpc = 0.800±0.03，其余单元与原 full 臂 verify 差 ≤ 0.03；(ii) B：drant ≥ 0.95（回到 base 1.021 的 0.05 邻域）；(iii) 剂量响应 A < C < B；(iv) blarn（只有被验证捕获的痕迹被降权，未捕获者保留——部分纠正）：B 臂 blarn 回升 +0.05~+0.35；(v) 对照单元（vexol/quibnar/sneel）臂间差 ≤ 0.05；(vi) 审计可回放：记录层能检索全部被降权痕迹及其原权重、RETRACT 条目数正确。

## R6 修订预注册（v2，首跑失败后、跑 v2 之前追加——透明条款）

**首跑（v1）结果与失败诊断**：COPY=普适程序（|x|/2·2+20bit，类无关）→ L3 k=1 仅 27%（≈25% 随机线）。
诊断：类无关的似然比在四类 argmin 中完全平票，argmin 退化为随机判决。
**架构教训（进日志）**：程序层的判别力必须来自变量与记忆内容的绑定；无参数普适程序对类后验零信息。

**v2 机制**：绑定版 COPY：`bound_copy_c(x) = grammar_c(w) + COPY_COST`，w = x 前半（x=ww 时）；
即"类 c 把 x 解释为：w 由本类文法生成 + 一条 COPY 指令"。四类同库同规格。
**v2 预测**：(i) L3 k=1 ≥ 60%，k=8 ≥ 75%；(ii) 总体 k=8 ≥ 81%（与 gzip 81.3% 打平以内）；
(iii) L1/L2/L4 变化 ≤ ±2pp（v1 已证 ±2pp 内，v2 绑定项只在 x=ww 时激活，非 ww 样本不变）。

## R6 修订预注册（v3，v2 失败后、跑 v3 之前追加）

**v2 失败诊断**：L3 的类签名是关系性的（x=w·w），w 内容随机 → 对 w 的类条件编码无类信息，判别退化为噪声。
**架构教训（进日志）**：内容绑定不够——判别力住在**专家权重的使用统计**里：L3 档案 100% 由 ww 构成 ⟹ COPY 原语使用次数 m 高 ⟹ 混合权重高。这正是锚点 5（原语晋升判据：宏节省×使用次数>定义长度）与 v1.5 缺口 B（程序空间先验）的实验面。

**v3 机制（混合专家，架构 ⑤ 的忠实操作化）**：
`score_c(x) = −log2( π_c·2^−copy_bits(x) + (1−π_c)·2^−grammar_c(x) )`
其中 copy_bits = (|x|/2)·2 + 20（普适程序编码），`π_c = (n_ww(archive_c)+0.5)/(k+1)`（COPY 原语在类档案中的使用率，平滑）。四类同库同公式。
**v3 预测**：(i) L3 k=1 ≥ 90%，k=8 ≥ 90%；(ii) 总体 k=8 ≥ 84% 且 ≥ gzip(81.3%)；(iii) L1/L2/L4 变化 ≤ ±2pp（非 ww 样本 copy 项为 0，退化为原文法 −log(1−π) ≈ 原值+≤0.03 bit）。
