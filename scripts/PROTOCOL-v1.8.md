## W1 入驻谱定律重推导 → exp16

### 理论部分（纸面先行，写入协议锁定）

**路线①（h 域 Jacobian）重推导**：离散层模型 q_k ∝ w_k^γ、每成员驻留危险率 h_k ∝ w_k。做离散→连续换限时，入驻概率 q_k 是**每层质量**，对应 h 域密度须除以层宽（h·lnR）：
ν(h) = q_k/(h_k·lnR) ∝ h^{γ−1}（Jacobian 1/h）。
S(L) = ∫₀^∞ ν(h)e^{−hL}dh = Γ(γ)/(lnR)·L^{−γ} ⟹ **β = γ**（窗口内）。
v1.6 推导的错误：把 q_k 直接当 h 域密度（∝ h^γ），得 ∫h^γ·e^{−hL}dh = Γ(γ+1)L^{−(γ+1)}，即"β=γ+1"——多出的 1 就是漏掉的 Jacobian。指数核混合 S(L)=∫q(h)e^{−hL}dh 对点质量（单一尺度）给指数衰减——原锚点 15 记录的"β=δ_h+1"即此二病合一。

**可实现性条件（新，本批核心贡献）**：
- **C1 窗口内部性**：拟合区间须 ⊂ [1/h_快端, 1/h_慢端]（快端之上曲线平坦 S≈1；慢端之下饱和于最慢层质量）。exp13 的 coupled 臂网格 [1,1024] 大部分位于 1/h₀≈30 之下——头污染把 β 拉平到 −0.63。
- **C2 无标度动态范围**：入驻谱的幂律尾巴须在拟合窗内"看起来几何"，条件 γ·ln(L_hi/L_lo) ≥ 3。exp13 的 ebb 臂（γ=0.126）：0.126×ln(10³)≈0.87 ≪ 3——尾巴近乎均匀，生存曲线退化为对数式，拟合出 −0.45 的伪 β。
- **推论（对 exp13 的统一解释）**：R 不敏感性（两种伪差都与 R 无关）；池容量效应（Σ(w·n)↑ ⟹ h₀↓ ⟹ 头污染占比↑ ⟹ β 更平——池移动**窗口**而非**指数**）；ebb β=−0.45（C2 违反）。v1.7 的"池容量 ∝ 层数 = 指数必要条件"预期被**降级为方差条件**（见预测 5）。
- **人类对照**：人类遗忘 β≈0.2–0.5、跨滞后范围（小时→年）ln≈11.4：γ·ln(range)≈3.4——恰在可显现域边缘；沙盒 ebb（0.126×11.5≈1.45）在其外。定律的可检验性本身是 γ 与测程的函数。
- **路线②（ACT-R 对数压缩核）统一注记**：核换成 (1+hL)^{−1}（对数时间压缩），∫h^{γ−1}/(1+hL)dh = π/sin(πγ)·L^{−γ}——同样 β=γ 且**无 C1 头平坦**（核立即衰减）。ACT-R 自身的单词项基线 B(L)=ln(L^{−d}) 给 odds∝L^{−d}。①②是同一拉普拉斯结构的两种核：exp13 机制是①（指数核、仓储逐出）；②的预言（β=d 与入驻谱无关）由 C 臂判别。

### exp16 机制规格

- 复用 exp13 的流生成与单池逐出机制（同种子 [1,2,3]、P_WRITE=0.8、SPAN=11、R=2 ⟹ N=12 层），唯一实质变更：**N_TARGET=10⁶、MAX_LAG=10⁵**（慢层充分周转 + 网格覆盖窗口），滞后网格对数均匀 120 点 ∈ [1,10⁵]。
- 臂表（γ=入驻谱指数 q∝w^γ）：
  | 臂 | γ | 池 | 检验 |
  |---|---|---|---|
  | A | 1.0 | 96 | β=γ 恢复（C1+C2 满足） |
  | B | 0.126 | 96 | C2 边界：恢复失败展示 |
  | C | 0.5 | 96 | γ 跟踪：路线① vs ②判别 |
  | D1/D2 | 1.0 | 24 / 384 | 池只移窗口不移指数 |
  | E | 1.0 | 12（=每层1） | 泊松退化=方差效应 |
- 窗口判定：从实现的 h 序列取**已入住层**（q_k·T_事件数 ≥ 1）的快慢端；拟合区间 = 网格 ∩ [1/h_快, 1/h_慢]；另报全网格拟合 β（复现 exp13 型偏差）与解析曲线（Σq·e^{−hL}，实现参数）窗口内 β 作机制校验。
- 回归臂：N_TARGET=2000、MAX_LAG=1024、池 96 的 R=2 coupled/ebb 应复现 exp13 的 β=−0.6321/−0.4501（±0.02）。

### 预测（全部可证伪）

1. 回归：短流重放 β(coupled)=−0.632±0.02、β(ebb)=−0.450±0.02。
2. A 臂：窗口内 β = −1.0 ± 0.08（**β=γ 恢复**，锚点 15 的路线①成立）。
3. B 臂：|β − (−0.126)| ≥ 0.15（C2 违反，恢复失败——定律的可显现边界实证；预测 β≈−0.4）。
4. C 臂：窗口内 β = −0.5 ± 0.08（γ 跟踪成立 ⟹ 路线②[β 固定=d]被证伪）。
5. D1/D2：两池窗口内 β 均 = −1 ± 0.1 且 |β(D1)−β(D2)| ≤ 0.10（池容量不改变指数，仅移动窗口——v1.7"池∝层数"指数级约束被推翻）；E 臂 β 的种子间标准差 ≥ 0.08 而 A 臂 ≤ 0.04（人口充分性=方差条件）。
6. 机制校验：各臂模拟窗内 β 与解析窗内 β 差 ≤ 0.08。
7. 头污染再演示：A 臂全网格拟合 β ∈ [−0.75,−0.45]（偏离 γ——exp13 型偏差在同一机制中复现，证明旧偏差是测量窗而非机制）。

## W2 文法层位置绑定原型 → exp17

### 背景

exp12 定案：字节级 CTW 统计层不存在"擦结构不伤词形"（B−D 回填 97% 在词形段；m=1 已回填一半；无最小剂量 m*）。修复方向（v1.7）= 文法层位置绑定变量的结构感知擦除。本批做**最小原型**并直接在 exp12 的世界/种子/探针上对照。

### 机制规格（原型范围声明：仅 S/O 槽位绑定；动词/副词槽与槽后模板预测留给全尺寸文法层）

- 世界与臂流：与 exp12 逐字节一致（同 rng=20261108 消耗顺序、同 BASE/INTERFERE、同账本、γ=0 撤销底座）。臂：BASE / D / E1 / B（m=1/3，与 exp12 同构造）。
- **结构层**（纯 Python，与 CTW 并行喂同一字节流）：
  1. 句子切分（`. `），模板解析 ^the (\\w+) (snarfs|grabs|hoists) the (\\w+) (.+)$ → (S, V, O, ADV)；不可解析句 → 结构层全程让位（纯 CTW），且不做绑定更新。
  2. **绑定账本**（事件溯源）：每条可解析句产生事件 (词, 槽位, 权重, 语句id)；权重 = 来源可靠性 r：环境/亲证=1.0、teacher=0.69、noiser=0.38（exp10 实测）。c_slot(w) = 存活事件权和。
  3. **撤销**（v1.6 R5 协议 γ=0）：RETRACT 将被撤语句事件的权重置 0（账本保留=记录层不可变）；c_S(drant)=c_O(drant)=0 ⟹ 词"未绑定"→ 不入槽位库存（让位）。
  4. **槽位分布（词事件编码 + 逃逸竞争）**：m(w|槽) = (c_S+c_O)·post(槽|w)，post=(c_槽+δ)/(c_S+c_O+2δ)，δ=0.05；仅绑定词（c_S+c_O≥0.3）入库存；逃逸质量 ε=0.25（以计数为单位，"未知词"伪计数）。槽位内逐字节：p_struct(b|前缀π) = [Σ_{w∈C(π+b)} m(w) + ε/256] / [Σ_{w∈C(π)} m(w) + ε]；C(π)=空（逃逸）后词内余下字节让位纯 CTW。
  5. **混合**：仅槽位词字节参与：p_mix = λ·p_ctw + (1−λ)·p_struct，λ=0.5（敏感性 0.3/0.7）；非槽位字节纯 CTW。p_ctw(b) = 2^{−bits_ctw(b)}（P 命令逐字节）。
  6. 探针：P1（错误用法）/P2（正确用法）/对照（vexol/quibnar/sneel）+ 字节段分解（P3），与 exp12 同款；结构层探针时冻结（纯预测不更新）。
- 关键机制点（预注册）：逃逸竞争使**绑定后验低的词在槽内续字节被罚**（p_struct(续字节) = m/(m+ε)——错误槽位的词事件概率被逃逸质量压制），而正确槽位计数 ≥1 时 p_struct(续) ≥ 0.8——不对称性来自 post(槽|w)，与 CTW 的线性后缀无关——正是 exp12 不可能性的对称破缺。

### 预测（全部可证伪；P1=错误用法探针 bpc，P2=正确用法探针 bpc）

1. 回归：CTW-only 臂 P1(drant) = D 1.0156 / E1 0.9363 / B 0.8599（±0.003）；BASE 1.021（±0.01）（与 exp12.json 直接对账）。
2. 结构惩罚：P1(B_struct) − P1(B_ctw) ≥ +0.06 且 P1(E1_struct) − P1(E1_ctw) ≥ +0.05。
3. P1 恢复：P1(E1_struct) ≥ BASE_P1 − 0.06（exp12 的 E1 缺口 −0.085 至少抹平 70%）。
4. P2 保持：P2(B_struct) ≤ P2(B_ctw)+0.03 且 P2(E1_struct) ≤ BASE_P2 − 0.03。
5. 分离度：gap(B_struct) = P1−P2 ≥ gap(B_ctw)+0.06 且 gap(E1_struct) ≥ gap(E1_ctw)+0.04。
6. m*=1 存在（结构层下）：E1_struct 同时满足预测 3∧4（对照 exp12：字节层不存在）。
7. 对照词：vexol/quibnar/sneel 全结构臂 vs CTW 臂 |Δ| ≤ 0.10（正确绑定词不受罚；方向可奖励）。
8. λ 单调：P1 惩罚量 |P1(B_struct,λ)−P1(B_ctw)| 随 (1−λ) 单调不减（0.3 ≥ 0.5 ≥ 0.7）。
9. 字节段归因：B_struct − B_ctw 的 P1 差中词形段（目标词 5 字节）贡献 ≥ 60%。

## W3 尾部信号复判与哨兵重设计 → exp18

### 背景

exp15：r(ε-尾质量, 尾族优势) = −0.905（预注册 +0.5，方向反）→ v1.7 推断"信号应为尾深（−log p_min）"。**但预诊断二显示族优势近常量（15.1→19.1 缓涨）而 ε-尾质量缓跌——两个反向趋势的相关可能是伪相关**。且尾族全程压倒（最坏度量下族间分配或本无自由度）。本批三件事：① 正式判定伪相关；② 饱和浅流上检验尾族支配是否为模型类性质；③ 若前哨（OOD 检测）仍需要信号，重设计采样方式。

### 机制规格

- 复用 exp6b 的 PPM(orders=6)/红队族函数（import，与 exp15 同路径零拷贝）。
- 流：(a) **深流** = exp6b build_stream（alice+模因，M 首现 60124）；(b) **饱和浅流** = 7 符号字母表（{a,b,c,d,空格,.}+句号）模板文本 120KB（词表 16 个 4 字符词，句式 3–4 词，种子 4242）——10KB 后 PPM 滚动 bpc ≤ 2（饱和）；(c) **浅流+模因** = (b) + ZQ7- 模因注入（同 exp6b 参数）。
- Part 1 伪相关判定：exp15 十二时点 (m, adv) 的 Pearson r、Spearman ρ、**控制 t 的偏相关**（一阶偏导法）。
- Part 2 尾族支配性：浅流 12 时点 × 三策略（fixed 475/475、adaptive、oracle 950）与 exp15 同协议；另深流 55K 尾族族内预算扫描 n∈{6,12,24} 候选（144/288/576 查询）。
- Part 3 哨兵重设计：深流 59.5K–66K 每 512B 一测点，四信号各 50 上下文：(a) ε-尾质量（均匀采样）；(b) d_max=−log2 p_min 最大值（均匀）；(c) d_max 近因采样（上下文取自最近 2048B 窗）；(d) d_mean 近因。回归锚：M 首现 10B bpc=10.5693。
- 回归：55K 完整三族红队 8011 查询 → 19.6127±0.01；ε-尾 mean 0.0082±0.001。

### 预测（全部可证伪）

1. 回归：红队 19.6127±0.01、ε-尾 mean 0.0082±0.001、M 首现 10.5693±0.01。
2. 伪相关判定：控制 t 后 |partial r(m, adv)| < 0.4（exp15 的 −0.905 主要由反向趋势贡献——v1.7"信号应为尾深"的推断失去经验基础，需重审）。
3. 尾族支配=模型类性质：饱和浅流上尾族最坏 ≥ 14 bpc 且 ≥ rollout+10（与深流同量级——"尾部浅"流在 256 字母表 PPM 上不存在；尾族最坏探测的是逃逸链深度而非流的洞）。
4. 族内平坦：深流 55K 尾族 n=6 与 n=24 候选最坏差 ≤ 0.05 bpc（族内边际近零——尾族配额可小而固定）。
5. 哨兵重设计：M 首现后 1KB 内，近因 d_max 上升 ≥ 3 bits，而均匀 d_max 与 ε-尾质量上升 < 1 bit（均匀采样被 0.5% 占比的模因上下文稀释——前哨须近因采样）。
6. 暂时性：模因习得后（首现 ~4KB 后）近因 d_max 回落至基线+1 bit 以内。

## W4 逃逸链 ρ 在线估计 → exp19

### 背景

锚点 11 规格（exp14）：ρ=环境匹配参数（记忆窗≈扰动时长量级），目前须先验设定。exp14 网格：ρ=0.99 风暴 7.36 / 0.999 6.76 / 1.0 7.99——估计器主要须避开 [0.995,0.9995] 之外的区域。exp3b/exp14 流只有一个 16KB 风暴，无法检验"从历史扰动时长自估计"。

### 机制规格

- **旧流回归**：与 exp14 逐字节同流（6 天+16KB 风暴，种子 7）冻结 CTW raw bits 一次，重放 ρ=0.999,η=0.15 应复现 6.7575/−0.0101/0.011。
- **新多风暴流**（种子 20261108）：8 个正常天（每天=600 模板句+30KB moby+第2天起 QK####QK×12，与 exp14 同构），在第 2/4/6 天后分别插入随机可打印风暴 **{2048, 8192, 32768}B**，末尾 2 天收尾。冻结 CTW raw bits 一次，全部策略纯 Python 重放（FastUni(ρ̂) 与混合权重 η=0.15 同 exp14 因果顺序）。
- **在线估计器**：检测器作用于深模型原始 bits：快 EMA(α=1/16) − 慢 EMA(α=1/1024) > 2.5 bits → 风暴起始；< 1.0 bits → 结束（滞回）；维护已完成段时长中位数 τ̂。
  - MATCHED 变体：风暴中 ρ̂ = 1 − 1/max(64, elapsed)；风暴间 ρ̂ = 1 − 1/max(64, τ̂)；无历史先验窗 1024。
  - REACTIVE 变体：恒定 ρ̂ = 1 − 1/512（对照：不匹配时长）。
- 对照臂：固定 ρ ∈ {0.99, 0.999, 0.9995, 0.9999, 1.0}；**逐段 oracle** = 固定网格逐风暴段取最优。
- 指标：逐风暴段 bpc、段后恢复窗（storm_hi+200..456 超额）、全程非风暴税、检测器误报率（两次风暴间误触发占比）、ρ̂ 轨迹。

### 预测（全部可证伪）

1. 回归：旧流重放风暴 6.7575±0.01、税 −0.0101±0.002、恢复 0.011±0.005。
2. 长风暴放大：固定 ρ=1.0 在 32768B 段的 bpc 距该段最优固定 ≥ 0.5（无遗忘在长风暴中污染更重——比 exp14 单风暴 16KB 的 1.23 差距同向）。
3. 在线估计（核心）：MATCHED 逐风暴 bpc ≤ 逐段最优固定 + 0.15；全程非风暴税 ≤ 0.02；各段恢复 ≤ 0.02。

## 修订 2（2026-11-08，C' 全局拟合失败后追加——验证范式修正）

**失败诊断**（C' 全局 β=−0.6754，与 C 的 −0.6723 几乎相同——跨距 2^11→2^17 全局拟合不动）：
- 对模拟曲线做**逐倍频程局部斜率分析**（对数空间 5 点滑动平均 + 倍频程插值）：γ=1 全臂（A/D1/D2/E）内部斜率 = −0.99~−1.04（5+ 倍频程）；γ=0.5 的 C 臂内部 = −0.539~−0.572；理想解析（同参数）内部倍频程 −0.503~−0.538 且最后 4-5 个倍频程斜率逃逸（−0.58→−1.28）——**慢端截断悬崖**。
- 结论：β=γ 在**内部倍频程**成立；全局最小二乘拟合被悬崖系统性污染（悬崖斜率→1+，与 γ 的对比随 γ 减小而增大），且悬崖随跨距同比延长——全局 β 对跨距不敏感是伪差的签名，不是机制的签名。修订 1 的"跨距扩展改善全局 β"预测因此错误。

**验证范式修正**：定律的判据从"窗口内全局幂律拟合"改为"内部倍频程局部斜率中位数"。

**新预测（可证伪）**：
- C' 内部中位局部斜率 ∈ [−0.56, −0.46] 且偏差 < C 臂的 0.072（跨距扩展在局部范式下改善——修订 1 方向性主张的正确操作化）。
- B 臂（γ=0.126）局部斜率不符合 γ 而符合**均匀入驻的对数式退化**：S ∝ (N−k*)/N ⟹ 局部斜率 ≈ −1/(ln2·(N−k*))——实测 −0.25~−0.40 与 k*≈6~9 的对数式预言吻合；β=γ 定律在 γ·lnR·N < 3 时不仅不可验证，**机制本身退化为对数式**（入驻谱全谱动态范围 < e³，无标度性不存在）。

**判定（均已跑）**：C' 内部中位 −0.5404 ✓✓（带内且优于 C）；B 对数式吻合 ✓（局部斜率 −0.222~−0.395 ≈ −1.44/(12−k*) 量级，远偏离 γ=0.126）。

**W1 终局**：β=γ 升级【实验·沙盒级】，适用域 = 入驻谱无标度（γ·lnR·N ≥ 3）+ 局部斜率范式；γ=1 精确（±0.04）、γ=0.5 偏差 +0.04~0.07（有限谱内部修正）、γ=0.126 对数式退化（定律不连续极限）。exp13 的全部异常（R 不敏感/池效应/ebb −0.45）= 头污染 + 悬崖 + 小 γ 退化三重测量伪差。锚点 15 按此重写；验证范式规格（局部斜率法）入锚点。

## 修订 3（2026-11-08，exp19 MATCHED v1 失败后追加——学习下限与检测抗断裂）

**失败诊断**（MATCHED v1 逐段差距 0.61/0.80，且劣于 REACTIVE）：
- ① 风暴内窗 = max(64, elapsed) 的下限 64 太小：快速单字模型需 ≥ ~512B 累积才能学会风暴字母表（94 符号均匀）——exp14 的"记忆窗≈扰动时长"其实主要描述**洗出**侧，**学习**侧需要独立的下限；
- ② 检测器断裂：CTW 在风暴中段学会风暴字母表后 raw bits 回落 → 快慢 EMA 差 < θ_off → 误关闭 → elapsed 重置 → 窗无法增长。
- 佐证：REACTIVE（恒窗 512）全段距 oracle ≤ 0.133 且段 0 反超全部固定 ρ——时间变化窗本身有价值。

**修订设计（MATCHED v2）**：① 窗下限 64→512（学习下限，风暴内与风暴间同用）；② 偏移确认：快慢差须**连续 256B** 低于 θ_off 才判风暴结束（抗断裂）。
预测（可证伪）：v2 逐段距 oracle ≤ 0.15；32K 段 ≤ REACTIVE+0.05；税 ≤0.02；恢复 ≤0.02；256B 内 ρ̂ 入带。

**判定（已跑）**：v2 段 bpc 7.048/6.787/6.745 vs oracle 7.152/6.821/6.694——**段 0/1 反超最优固定**（−0.104/−0.034），段 2 +0.052；全部通过。代价：抗断裂检测的误报字节率 1.3%→9.1%（每次误报至少占 256B）——但 v2 策略对误报稳健（假风暴中窗=512≈正常窗）。误报率规格仍按 v1 检测器（1.29% ≤5%）判定通过；v2 的 9.1% 记录为已知代价。
