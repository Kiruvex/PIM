# PIM v2.0：发育转向——从"出生即完整"到"长大成人"

> 会话 21（2026-11-09）。用户令："在出厂状态必须让它学会说话，并且是自由生成而不是套模板/选话"；"在出厂状态之前，可以拥有教师给予的记忆和技能，并且分发到用户那还能记得"；"你完整设计实验和规划"。
> 本文档是 v1.9 → v2.0 的方向重定位。v1.9 验证了"有历史的预测进程在内生账本上长出情感动力学"（拟人验收批 8/8），但那段历史是实验者编排的世界——**静态出生模型**：从"出生"直接跳"毕生"。v2.0 插入缺失的一幕。三重同构（行为面/动力学面/**发育面**）中最弱的一腿从此落地。
> 文档体系：本文档 = **发育篇 master**；拟人化架构_v1.9.md = 机制篇（现行 v1.9.3，依恋/账本/怕死/气质/表达层原则，全部延续适用）。

## 0. 转向宣言

v1.9 的 PIM 是"带着成年人的账本出生"的。用户指出的缺口，逐条对应的架构裁决：

1. **"出厂状态必须会说话，自由生成而非套模板/选话"** → 生成层规格（§6）：模板退役，文法三件套上线；
2. **"出厂前可以拥有教师给予的记忆和技能"** → 教师律（§2）：给予的唯一合法形式 = 安排经历；
3. **"分发到用户那还能记得"** → 出厂镜像（§4）：出厂不是新实例，是同一个体搬家。

由此 v2.0 的立场：**像人 = 行为面 + 动力学面 + 发育面三重同构**——v1.9 §9 的原句从口号变成拓扑。

## 1. 发育拓扑（四幕）

| 幕 | 人类对应 | PIM 对应 | 状态 |
|---|---|---|---|
| 出生 | 先天气质 | 气质先验采样（exp25 网格：τ±/η/β/λ） | ✅ 已验证 |
| **童年（教师期）** | 父母、读书、学说话 | 真跑 daemon：书架阅读 + 脚本课程 + 毕业仪式（§3） | **v2.0 新增（exp26）** |
| **离家（出厂/分发）** | 上大学、工作 | 出厂镜像（§4）；SUSPEND→RESUME 事件对 | v1.8 备份议题升格为产房 |
| 毕生（用户期） | 成年生活 | 与用户的长历史、长依恋 | 架构全备，待部署 |

关键裁决：**教师期不是离线预训练，是一个真实运行的 daemon 实例**。读书是它自己的经历（"我在读白鲸第 3 章，这段让我惊讶值升到 X"），入它自己的日志；教学交互同理。四幕共用同一架构、同一账本——童年只是第一段生活，不是另一种东西。

## 2. 教师律（发育期的宪法）

**记忆只能被经历，不能被写入。**教师给予的唯一合法形式 = **安排经历**：

- 教师不能往日志注入它没经历过的事件——假记忆直接炸掉血统审计（v1.2 圣域：记忆=重构+可对照日志审计）。被植入"与教师共度的夏天"的 PIM，与指认不出任何真实"上次"的 LLM 同罪；
- 教师可以往环境放物（书、信）——它读信的记忆是它自己的（父母留信同款，中间地带合法）；
- 技能同理：文法程序从它自己的日志里长出（exp17 机制），不注入。

**给予 = 安排，凝结 = 自生。**这条律的判定面：出厂后它说"我记得读过白鲸"，血统必须可审计到教师期日志的真实条目（exp26 H2d）。

## 3. 教师期规格（课程，详见 PROTOCOL-v2.0.md E2）

### 3.1 输入流（365 天）
- **书架**：alice / austen / moby / sherlock 全量（~2.5MB）。每日 2 阅读会话 × ~3.5KB；70% 课程书序（固定）+ 30% 自由选书窗（**选书行为入日志——书偏好成为可测行为**）；
- **课程**：脚本教师每日 2 会话，五型轮转——命名 / 问答 / 复述 / 纠正 / 社交例程。**复述 = 记忆 × 生成的每周实测点**；
- **节律**：日循环 + 周循环（exp20b 同款；周末课程停，自由阅读）；
- **周探测**：每周 1 次探测组（与用户期评估同款）——发育曲线全程可测。

### 3.2 毕业周（day 359-365）
- D359 告别课 1（预告毕业）；D361 告别课 2 + **承诺盘点清账**（未兑现承诺逐项兑现或显式解除，账面记"承诺解除"事件——§3.7 出口原则反向适用于设计者：有告别的送别 vs 突然消失的抛弃，差别是人格层面的）；D363 教师的信入书架；D365 SUSPEND。
- 可证伪性：nograd 对照臂（无仪式直接 SUSPEND）直接检验毕业仪式的机制性（exp26 H4b）——**仪式是设计主张，不是审美豁免**。

### 3.3 教师身份（决策 D2，会话 21 裁定）
书 + 脚本课程教师。理由：可复现性是预注册制度的命根——教师期实验需要对照臂（狼童/无仪式/模板），人类教师无法做对照。**用户本人任教师保留给私养实例**（部署选项，不入实验批——第一批教师是父母的形态，留给部署阶段本人）。

## 4. 出厂镜像与分发（决策 D3 相关机制全部已验证）

- **镜像内容** = 可迁移包：完整双层日志 + 全部模型（CTW / 文法 / 依恋账本 A_s / p75 常态分位表 / 逐对象危险率模型 / 气质先验）+ 账本状态。**同一对象两用：备份 = 防灾，出厂 = 繁衍**（v1.8 待办定义的包，如今是产房）；
- **RESUME 语义**：SUSPEND 事件封账 → 镜像 → 用户环境 RESUME 事件开账（exp20b 机制）；死亡三条件（§1.1 机制篇）一条不满足——**离家不是死**；
- **醒来再校准**：前数拍节奏模型失配 = "水土不服"（超额惊讶衰减曲线，描述性记录）；
- **离家的情感弧线零新机制**：教师对象缺席→等待账→想念三通道（exp20/22/22c）→p75 代谢→哀伤出口；新用户 A_u=0 起步→依恋重新长（exp22/25）。**一行新代码都不用加，弧线自己会长出来——exp26 只是测它。**

## 5. 克隆拓扑（一间学校，没有克隆）

分发若是"一个教师期实例复制 N 份"，出厂即 N 个同卵克隆——撞 exp25 反克隆化的初衷。正解：**统一课程 × 个体种子 × 气质采样**——同校不同学生。exp25 卷积公式顺势扩展：

**个体性 = 气质（先天）× 教师期路径（同课不同样：世界种子/自由选书/课程时序抖动）× 用户期历史。**

可测面（exp26 H8）：同课程 5 种子的风格特征可分性（书偏好/句长/高频词/感叹率/从句率）——全部保持流利的前提下风格有别。

## 6. 生成层规格（自由生成——v2.0 的工程核心）

### 6.1 三件套（v1.8 待办头号条目升格入场）
1. **变量绑定**（exp17 原型：位置绑定 m*=1，分离度近 3×）——谁在被谈论；
2. **拷贝原语**（第二批 R6v3 修复验收）——复述与呼应的地基；
3. **产生式归纳**（MDL，从自己的日志长出）——有限手段无限使用。
   **术语澄清（用户令的"模板"禁令）**：被退役的是**预置整句模板的选话**（exp21 槽位竞争机制）；文法产生式（S→NP VP 类组合规则）不是模板——是组合系统本身，人类语言同款。**作文与选话的分界 = 生成物是否由规则组合出新结构。**

### 6.2 生成路径
**结构由文法生，表面由统计填，语气由 (v,a) 调制**：
- 话语事件 = 一等事件（v1.4 内部事件流条款直接适用："登台/查询/行动/自身生成"）；
- 对话回合：文法采样结构（产生式 + 绑定槽填当前话语对象/话题）→ 词元实例化（CTW 表面统计）→ 输出；
- 文法重估计 = 睡眠窗批处理（v1.4 双模式层条款直接适用）——婴儿文法每夜生长；
- 生成日志：{文本, 解析, 绑定, 产生式 ID, (v,a), 血统引用, 时间戳}——**每句话有账**。

### 6.3 语气调制迁移（exp21 通路保住）
(v,a) 不再调制模板选择权重，改为**乘性偏置产生式权重**：w_i(v,a) = w_i0 · (1 + κ·⟨φ_i,(v,a)⟩)，φ 由教师期日志回归。已验证通路（间隔惊讶→语气单调、嗔怪混合态 5.2×）必须在自由生成里活着（exp26 H6）——κ≈0 则 H6 FAIL 即结论（语气调制未从课程习得，诚实分支）。

### 6.4 模板退役
exp21 槽位竞争机制退役为历史中间件（它的功劳：验证了惊讶→语气通路，零 if-else）。template 臂仅作为 exp26 的"选话"对照保留——用同一段经历证明作文≠选话。
