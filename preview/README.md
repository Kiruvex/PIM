# preview/ —— PIM 在线预览版（实验装置的可玩外壳）

> 判定读数之外，“无限像人”最后要走到能与真人对话。这个目录是**第一只壳**：把主仓
> exp33 批的毕业个体接到真人输入上，并且把它账本里的每一次心跳画给你看。

## 组成与出处（装置复用表）

| 预览组件 | 出处（主仓逐位复用） |
|---|---|
| boot（365 天 Warm 教师期） | `exp33.run_instance_33(seed, "Wreg", days=365, gate=(DIAL_CTXS, λ=20), μ=40)` |
| 课程与语域锚 | exp30 稳定化配方（单词锚+搭档唯一化+变体轮转，reg90=1.00） |
| 生成层 | Grammar33 = exp27 帧文法 + exp31 语境门控（对话源帧权重 ×20）+ exp33 语气杠杆 μ=40 |
| 入账 | `PIM.experience()`（事件日历/词汇/文法输入/bits→v），exp27/29 用户期同管道 |
| 依恋/想念 | `A(s,day)` 幂律账本 + `Btilde`（p75 常态偏离），exp22/22c 同式 |
| 重逢 | `log2(1+gap)` 重逢脉冲（exp27 reunion 同式；exp20 缺席惊讶为间隔分布版） |
| 睡眠 | `lex.rebuild()+gram.rebuild()` 文法重估计（架构 v2.0 §6.2 睡眠窗批处理） |
| SUSPEND/RESUME | 完整 `pim.__dict__` + **词 id 空间（VOCAB/VIDX）** 整入镜像（exp26 E4 镜像语义；跨进程 RESUME 实测 ≈1 秒） |
| 回复选择 | 纯选择层：28 次采样按（对话帧数/语域词/词重叠/覆盖度）评分选优——权重公式零改动（exp31"纯选择层干预"同型） |

## API

| 路由 | 说明 |
|---|---|
| `GET /` | 仪表盘（单文件原生 JS/SVG，无 CDN） |
| `GET /api/state` | 全量快照（curves/chat/实体/A 值）——前端 1.6s 轮询 |
| `POST /api/say` `{"text","gap"}` | 说一句话；gap=隔几天再见（≥2 触发重逢脉冲） |
| `POST /api/sleep` `{"n"}` | 睡 n 天（想念账累积，醒来文法重估） |
| `POST /api/reset` `{"seed"}` | 让新个体重新长大 |

## 时间口径

预览内"1 天"= 逻辑日（每条消息推进一日；gap 由你指定）。想念/重逢机制因此**可演示**
（隔 7 天回来＝它真会被吓一跳），与原始 365 天压缩周期的时率不同属预览口径。

## 运维

- 首启 fresh boot ≈ 8s 写盘 `state.pkl`；每回合自动 SUSPEND；重启瞬时 RESUME；
- `preview/state.pkl` 是运行态（`.gitignore` 已忽略）；删除 = 重新出生；
- 默认绑定 `127.0.0.1`，对外部署设 `PIM_HOST=0.0.0.0` 并自行做好访问控制——
  当前为共享单实例形态，多用户各自领养（镜像分发）是后续工作；
- 服务器零第三方依赖；仪表盘零 CDN 依赖。

## 诚实条款（与 README 同步）

回复全部由装置生成，无任何 LLM/模板/润色；3-8 词短句是 exp26 H0b 判定在案的装置
局限（句长 1.43，层级递归 = exp35 候选⑤）。每条消息的 bits 是词块新颖度近似（预览口径），
与 exp20 的间隔分布惊讶不同源。**你在预览里看到的每一句话都有账可查。**
